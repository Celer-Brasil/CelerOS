# System apps

**English** | [Português (BR)](/Celer-Brasil/CelerOS/wiki/Apps-de-Sistema)

CelerOS system apps are **JavaScript** (ES5, Duktape) and live in the
LittleFS partition, mounted at `/local` — the firmware carries only the
core. That cut ~330 KB from the CYD image and became the house standard:
the 14 apps in `data/apps/` are all JS (App Store, Barebone, Chat IA, HTTP
Demo, Help, Installer, Matilha, Qwen, Settings, Snake, Terminal, Touch
Test, Watchface, Web Server) — Matilha (API 27) is the pack panel: mesh
toggle, members with roles, direct messages and the roaming music
handoff. Boards can add their own on top (overlay): Dog Face
on the dog; Alarmes, Atividade, Celular, Clima, Musica and Timer on the
watch.

## Layout

```
data/
├── apps/<Name>/   # app.json + main.js (+ icon.png); folder name = displayed name
└── icons/<id>.png # GENERATED by tools/make_icons.py (RGBA quantized to RGB565)
```

[`hub_apps/`](hub_apps) — 13 apps today (2048, Breakout, Calculator,
Previsao, System Info, **Celer Remote** and more) — follows the same
layout, but is published to the hub instead of shipping in the factory
image. Celer Remote (API 11) is the robotics flagship: it scans
for nearby CelerOS over Celer Link (BLE), connects and drives a robot with a
D-pad while showing its telemetry — a full `CelerLink` + `System.gpio.servo`
reference.

## app.json

Required fields:

| Field | Rule |
|---|---|
| `name` | display name |
| `packageName` | unique installation key (`celeros.<x>` for system apps; the first publisher on the hub owns it) |
| `version` | semver; the hub rejects republishing the same version without `--force` |
| `api` | minimum `CELEROS_API_LEVEL` — declare the lowest one you actually use |

Optional: `author`, `description`, `type` (`System|App|Game`), `category`,
`system`, `order` (launcher order), `icon` (id in `data/icons/`), `topbar`,
`changelog`. Never fill `size`/`md5` by hand — the hub computes them at
publish time.

Full packaging guide in
[App development guide](/Celer-Brasil/CelerOS/wiki/App-Development-Guide).

## House rules

* **ES5 only**: no arrow functions, `let`/`const`, `class`, template
  literals or `Promise`. Use `var` + `function` + concatenation.
* The app loop is a blocking `while` with `System.delay()`; exit via
  `System.exitApp()`. Since API 18/19 some asynchronous calls take a
  callback (`AI.chat`, `Mic.start`) — it fires once, inside the app's own
  cycle (`present()`).
* Work in virtual 240x320 coordinates and pick colors from
  `System.theme()`. Never hardcode the screen size.
* Persistent state in `/local/...`, never inside another app's folder.
* System app UI strings are in Portuguese (the project's home language;
  the fonts cover Latin-1).

## How an app reaches the device

| Route | Command |
|---|---|
| Factory image | `tools/flash_data.sh <board> <port>` (rewrites the whole LittleFS partition) |
| A single app, over serial | `python3 tools/celerctl.py apps install "data/apps/Settings"` |
| From the App Store | hub `https://os.celer.tec.br` (Wi-Fi) or Installer via SD |

**Firmware OTA does not update apps**: OTA (Settings → System Updates,
web `/update` or `celerctl ota push`) swaps only the firmware image and
never touches LittleFS. Apps update through the routes above.
